' ============================================================================
' 易语言版 私聊消息自动回复机器人
' ----------------------------------------------------------------------------
' 对应 Python 版 private_reply_bot.py，架构一致：
'
'   收事件：NapCat 的「HTTP 上报」(httpClients) 把事件 POST 到本程序的服务器组件
'   发消息：本程序作为 HTTP 客户端调 NapCat 的 HTTP API (send_private_msg)
'
' 为什么用 HTTP 上报而不是 WebSocket：
'   易语言标准库只有 TCP，没有 WebSocket 客户端。NapCat 的 httpClients 正好是
'   「NapCat 主动 POST 事件到你」，用服务器组件收即可，零第三方模块依赖。
'
' ----------------------------------------------------------------------------
' 【重要】NapCat 用 Transfer-Encoding: chunked 上报，且 chunk 长度是「字节数」。
' 中文在 UTF-8 里占 3 字节，所以全程必须用「字节集」处理，绝不能先 到文本() 再
' 按字符数比较长度，否则中文消息必然解析失败。这是本代码最关键的一点。
' ----------------------------------------------------------------------------
'
' 前置配置（NapCat WebUI 里改，或直接改 onebot11_<QQ>.json）：
'   httpServers : 127.0.0.1:3000  token=pydemo_token_2024   ← 本程序发消息用
'   httpClients : http://127.0.0.1:5700/  reportSelfMessage=true  ← 本程序收事件用
'
' 界面需要放的组件：
'   服务器1      —— 接收 NapCat 上报（端口 5700）
'   客户1        —— 调用 NapCat HTTP API（连 127.0.0.1:3000）
'   编辑框_日志  —— 显示日志
' ============================================================================
